Intel NPU OpenVINO 壓力測試教學

這份教學示範如何在 Windows 上安裝 OpenVINO、確認 Intel NPU 被偵測到，並用簡單的卷積模型讓 NPU 跑到高負載。適合想快速驗證 Intel AI Boost / NPU 是否正常工作的朋友。

1. 這份教學會做到什麼

完成後，你會得到一個 OpenVINO IR 模型，並用 benchmark_app 指定 -d NPU 與 -infer_precision NPU:i8 執行 INT8 推論。成功時，Windows 工作管理員的 Performance > NPU 會看到使用率上升，並可用 throughput 換算這個 workload 的 effective TOPS。

2. 環境準備

請使用 Windows PowerShell，建議不要在 C:\Windows\System32 操作，先切到自己的工作資料夾。

cd C:\Users\123\Documents\Codex\OPENVINO

建立 Python 虛擬環境

py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install openvino numpy
如果 PowerShell 不允許啟用虛擬環境，先執行： 
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
然後重新執行 .\.venv\Scripts\Activate.ps1。

3. 確認 OpenVINO 看得到 NPU

最容易的檢查方式是用一行 Python 指令：

python -c "import openvino as ov; print(ov.Core().available_devices)"

如果輸出包含 NPU，例如：

['CPU', 'GPU', 'NPU']
看到 NPU 就代表 OpenVINO Runtime 已經偵測到 Intel NPU。接下來就可以指定 -d NPU 執行模型。

常見錯誤：把 Python 貼到 PowerShell

以下是 Python 語法，不能直接貼在 PowerShell 的 PS C:\... 提示符號後面：

import openvino as ov
core = ov.Core()
print(core.available_devices)

正確做法是先輸入 python 進入 >>> Python 互動模式，或使用上面的一行指令。

4. 建立 NPU 壓力測試模型

建立一個名為 make_npu_model.py 的檔案，內容如下。這個模型本身用 FP16 權重儲存，但後續會用 -infer_precision NPU:i8 要求 NPU plugin 以 INT8 inference precision 編譯執行。

import numpy as np
import openvino as ov
from openvino import opset11 as ops

input_node = ops.parameter([1, 3, 224, 224], dtype=np.float16, name="input")

x = input_node
in_channels = 3

for i in range(12):
    out_channels = 64
    weights = np.random.randn(out_channels, in_channels, 3, 3).astype(np.float16) * 0.02
    const = ops.constant(weights)

    x = ops.convolution(
        x,
        const,
        strides=[1, 1],
        pads_begin=[1, 1],
        pads_end=[1, 1],
        dilations=[1, 1],
    )
    x = ops.relu(x)
    in_channels = out_channels

model = ov.Model([x], [input_node], "npu_stress_conv")
ov.save_model(model, "npu_stress.xml")

print("Saved npu_stress.xml")

執行：

python make_npu_model.py

成功後會產生：

  • npu_stress.xml
  • npu_stress.bin

5. 開始用 INT8 壓力測試 NPU

先跑 60 秒確認能正常執行。重點參數是 -infer_precision NPU:i8，這會要求 NPU 使用 INT8 inference precision：

benchmark_app -m npu_stress.xml -d NPU -infer_precision NPU:i8 -hint throughput -t 60

如果成功，再拉長到 5 分鐘：

benchmark_app -m npu_stress.xml -d NPU -infer_precision NPU:i8 -hint throughput -t 300

建議把結果同時存到文字檔，後面換算 effective TOPS 會比較方便：

.\.venv\Scripts\benchmark_app.exe `
  -m .\npu_stress.xml `
  -d NPU `
  -infer_precision NPU:i8 `
  -hint throughput `
  -t 300 `
  | Tee-Object .\npu_int8_benchmark.txt

如何確認真的在跑 NPU

  1. 按 Ctrl + Shift + Esc 開啟工作管理員。
  2. 切到 Performance。
  3. 點選 NPU 0 或 Intel(R) AI Boost。
  4. 執行上面的 benchmark_app 指令。
  5. 觀察 NPU 使用率是否上升。
看到輸出包含 EXECUTION_DEVICES: NPU 與 INFERENCE_PRECISION_HINT: <Type: 'int8_t'>，再搭配工作管理員 NPU 使用率上升，就代表 INT8 NPU 測試成功。

6. 如何換算 Effective TOPS

工作管理員顯示 NPU 100% 只代表 NPU 很忙，不等於直接得到 13 TOPS。要估算這個 workload 的 effective TOPS，需要使用 benchmark_app 最後輸出的 Throughput。

換算公式

Effective TOPS = 每次 inference operations × Throughput / 1,000,000,000,000

這份教學產生的 npu_stress.xml 約為：

20.43 GMAC / inference
約 40.87 GOPS / inference

所以可以簡化成：

Effective TOPS ≈ Throughput × 0.04087

實際範例

如果 benchmark_app 最後顯示：

[ INFO ] Throughput: 122.28 FPS

換算結果就是：

Effective TOPS ≈ 122.28 × 0.04087
               ≈ 5.00 TOPS
Intel 規格頁上的 13 TOPS 是 NPU 的 INT8 peak theoretical TOPS。這裡算出來的是這個 OpenVINO 模型在這台機器上的 effective TOPS，會受到模型結構、compiler、memory bandwidth、driver、runtime 設定與散熱狀態影響。

用 PowerShell 自動換算

如果前面有用 Tee-Object 存成 npu_int8_benchmark.txt，可以直接執行：

$line = Select-String .\npu_int8_benchmark.txt -Pattern "Throughput:\s+([0-9.]+)"
$fps = [double]$line.Matches[0].Groups[1].Value
"Estimated Effective TOPS = {0:N2}" -f ($fps * 0.04087)

7. 排錯指南

  • 看不到 NPU：更新 Intel NPU driver，並確認裝置管理員內有 Intel AI Boost / NPU 裝置。
  • PowerShell 出現 ParserError：你可能把 Python 程式碼直接貼到 PowerShell。請改用 python -c 或先進入 Python 互動模式。
  • 模型不能編譯：NPU 對模型算子和 shape 有限制，建議先用這份教學的 static shape 模型測試。
  • 沒有看到 INT8：檢查指令是否包含 -infer_precision NPU:i8，並在輸出中尋找 INFERENCE_PRECISION_HINT。
  • NPU 使用率不高：模型可能太小或執行時間太短。可以把 -t 拉長，並確認使用 -hint throughput。
  • benchmark_app 找不到：確認已啟用 .venv，並已安裝 openvino。
  • 想停止測試：在 PowerShell 按 Ctrl + C。
